#+TITLE: sti_atio ontology, split into class files

The v8 ontology (=sti-atio-ontology-v8.ttl=), one file per class, PHP-style:
- Each file carries its own =@prefix= block (the =use= statements) and parses on its own.
- A property lives in the file of the class it depends on (its domain, or its range if
  the range is the less stable class). Dropping a folder therefore never leaves
  dangling terms behind in =base_classes/=.
- Enumeration classes sit next to their individuals, in the file of the property that
  uses them.
- =ontology.ttl= is the =owl:Ontology= header. =build.py= concatenates a profile into =dist/=.
