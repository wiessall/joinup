## Playwright Testing

Performs visual regression tests on a clean Drupal install with content provided
by `joinup_test_content`. Screenshots are taken and compared to reference
snapshots stored in Git. We use Selenium to prevent any hardware influence
instead of running browsers directly from the host machine. Fonts are
particularly susceptible to this...

### Run tests

```bash
ddev install
ddev playwright test
```

Test results are generated by playwright in the `test-results` folder.

Optionally, to see the HTML report run: `ddev playwright show-report tests/playwright/playwright-report --host 0.0.0.0`  
And access https://[your-project-name].ddev.local:9324/

### Update snapshots

To update reference screenshots, run:

```bash
ddev playwright test --update-snapshots
```

Make sure the changes look correct before committing!

For more details, refer to the [Playwright documentation](https://playwright.dev).
