#+Title: README

This module takes care of minting the URIs and providing functionality to write to the triplestore. It extends ~rdf_sync~ in the following ways:
  - skos mapping functionality. This is a basic design decision: Curators (human or machine) should be able to create semantic mappings between the various collection taxonomies. This is needed for a semantically meaninful derivation of a standardized derivation across all ~source_record~. This derivation is the ~atio_innovation~.

* Routes
** IdResolverController
Redirects calls to the uris of rdf entries to their drupal routes.
303 redirects to entity page, 404 for anything that can't be seen or doesn't exist
*** UriResolveEvent
does the actual replacement of the uri with the provided replacement uri. Get takes that provided uri, those are provided to the subscribers who use ~set~ to put in the correct replacement uri. Current subscriber(s):
  - ~sti_dedupe/ReplacedInnovationSubscriber~
****  ~sti_dedupe/ReplacedInnovationSubscriber~

** MappingExportController
Queries the triplestore about the mappings relevant to the node at path (always a collection as specified in the routes) and returns a ttl formatted 'Response'

** MappingOverviewController
$collection->access('update') uses current user in absence of specific user input.
Returns basically just the table as a php array

*** MappingCuration
  - what is self::FIELD: ~field_mappings~
  - mappings gets all entity references held by ~field_mappings~ and filters for those that are paragraphs of bundle 'mapping'
